# AeroMarine — Shipping & Exports Frontend

Mobile-first H5 web application (`max-w-[480px]`) built with React, Vite, and Tailwind CSS for **AeroMarine Shipping & Exports**.

## Features
- **Mobile Container:** Optimized for mobile screens with clay neumorphic design tokens
- **5-Tab Bottom Navigation:** Home, Income, Spin, Team, and Profile
- **Interactive Vessel Visuals:** High-definition photography and technical specs (TEU capacity, routes, tonnage, knots) for all container carriers
- **Curated AeroMarine Logo:** Scalable vector SVG emblem, horizontal brand header, and circular crest
- **Fleet Leasing Plans:** Segmented selector between Normal Fleet Plans and VIP Express Cargo
- **Interactive Wheel:** 8-segment lucky wheel with audio-visual spin feedback
- **Recharge Flow:** Quick amount chips (₹720, ₹285, ₹520, ₹1000, ₹2000, ₹4785) and UTR submission dialog
- **Withdrawal Flow:** 10% tax calculation with bound bank account confirmation

## Quick Start
```bash
# Install dependencies
npm install

# Start Vite development server
npm run dev

# Build production bundle
npm run build
```
